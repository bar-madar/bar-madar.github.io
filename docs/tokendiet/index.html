Why your requests are heavier than they need to be

Every request carries your CLAUDE.md, AGENTS.md, rules files and skill descriptions. Over time they fill up with repeated rules, release checklists, code samples and old history, and you pay for all of it on every turn, in tokens and in usage limits.

Lossless by design

What TokenDiet does

  • Removes repetition and noise
  • Moves instructions so they load only when needed
  • Asks before every change
  • Backs up every file it edits
  • Measures again so you see the result

What it never does on its own

  • Lower your model, effort or thinking
  • Make replies terser
  • Delete rules your agent still needs
  • Disable your MCP servers or tools

When one of these would save tokens, TokenDiet explains the trade-off and leaves the choice to you.

What it finds

Repeated rules

The same instructions in CLAUDE.md, AGENTS.md and rules files, or twice in one file.

Workflow sections

Release, review or migration steps that load on every request but matter only sometimes. TokenDiet moves them into on-demand skills or scoped rules.

History

Change logs and past decisions that rarely help with today's work.

Code samples

Long examples inside instruction files, replaced with a pointer to a real file.

Long files

Files past 200 lines, the length Anthropic recommends staying under for CLAUDE.md.

Always-on rules

Cursor rules set to always apply but written for specific files.

Broken links

Pointers to files that no longer exist, which send your agent looking for nothing.

Unused MCP servers

Servers Claude Code hasn't called in 30 days, so you can switch them off.

How it works

  1. Ask

    "Put this project on a token diet." Your agent runs the audit and shows the top findings with what each saves.

  2. Approve

    Pick the fixes you want. TokenDiet backs up each file, then applies the change exactly as its playbook describes.

  3. Compare

    It measures again and shows before and after for each agent. If you use Tokenmeter, the result appears in its dashboard.

Frequently asked questions

Will it make my agent worse?

It is built not to. TokenDiet only removes repetition and noise, or moves instructions so they load when needed. Anything that could affect quality, such as a smaller model or lower effort, is explained and left to you.

Can I undo changes?

Yes. TokenDiet backs up every file before editing it, into a .tokendiet/backup folder in your project, and one command restores them.

Does it send my code anywhere?

No. It runs on your computer with Node.js and reads only your instruction files and Claude Code's local logs.

How accurate are the numbers?

Token counts are estimates within about ±20%, because exact counts depend on each model's tokenizer. They are reliable for finding what is heavy and comparing before and after.

Does it work without Claude Code?

Yes. The audit covers Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI, Windsurf and Cline. The session usage check needs Claude Code, because other agents don't keep comparable local logs.
