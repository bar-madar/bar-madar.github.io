How they work together

Every request your agent sends carries the whole conversation and your instruction files. Tokenmeter makes that visible; TokenDiet makes it lighter.

  1. See it

    Tokenmeter shows each session's tokens and context fill, and suggests a diet when the context passes half the window or the prompt cache keeps missing.

  2. Trim it

    TokenDiet measures your CLAUDE.md, AGENTS.md and rules files, proposes lossless fixes, and applies the ones you approve.

  3. Track it

    Each audit shows up in Tokenmeter's dashboard as that project's instruction weight, before and after.

Frequently asked questions

Do I need both tools?

No. Each works on its own. Tokenmeter shows where your tokens go; TokenDiet reduces what your instructions add to every request. Used together, Tokenmeter also shows each TokenDiet audit and suggests one when a session gets heavy.

Is Tokenmeter really free?

Yes. Tokenmeter is open source under the MIT license, with the code on GitHub. TokenDiet is a separate, paid skill.

Which agents do they support?

Tokenmeter works with Claude Code. TokenDiet's audit covers Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI, Windsurf and Cline, and runs in any agent that supports Agent Skills (SKILL.md). Its session usage check needs Claude Code.

Does anything leave my computer?

No. Both tools run locally, read files on your machine, and send nothing anywhere. This website doesn't use cookies or tracking either.

What does "lossless" mean here?

TokenDiet only removes repetition and noise, or moves instructions so they load when they are needed instead of on every request. It never lowers your model, effort or thinking, and asks before every change.
