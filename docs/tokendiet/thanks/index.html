Thanks for getting TokenDiet

Here's how to install it and run your first diet. It takes about a minute.

1. Install it

Claude Code

Unzip the download into your skills folder (if your download has a different file name, use that). On macOS or Linux:

mkdir -p ~/.claude/skills && unzip tokendiet-1.0.0.zip -d ~/.claude/skills/tokendiet

On Windows, in PowerShell:

Expand-Archive tokendiet-1.0.0.zip -DestinationPath "$HOME\.claude\skills\tokendiet"

To install it for one project only, unzip into that project's .claude/skills/tokendiet folder instead.

Other agents

TokenDiet is a standard Agent Skill with SKILL.md at the root of the zip. Use Agensi's install instructions for your agent, or place the folder wherever your agent loads skills from.

2. Check Node.js

TokenDiet's scripts need Node.js 18 or newer. Check with:

node --version

If it's missing or older, install it from nodejs.org.

3. Run your first diet

Start a new session in your project and ask:

  • "Put this project on a token diet"
  • "Where are my tokens going?" (usage check, Claude Code)

Want to try it on a sample first? Ask your agent to "run the TokenDiet demo". In Claude Code you can also type /tokendiet. Your agent shows the findings and asks before changing anything. Backups go to .tokendiet/backup in your project.

Changes to always-loaded files apply from the next session. In Claude Code, that's after /clear, /compact or a restart.
